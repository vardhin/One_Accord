# Sword Glow & Detection (Rust Removal)

> A FUNCTIONAL maintenance upgrade. Deliberately kept SIMPLE and NOT tied to
> memory or emotional tradeoffs. Contrast with the consent/identity drama in
> `upgrades-and-identity.md`.

## The rule

**Rust blocks the sword's sensory channel. Removing rust restores detection.**

> Rust should NOT be tied to memory here. Maintenance unlocks perception.

The sword can **glow** when it detects enemies nearby — but only **after rust is
removed.**

## Rust/detection upgrade chain

| Stage | Capability |
| --- | --- |
| **Rusted blade** | No glow; maybe vague danger-sense only |
| **Edge cleaned** | Better cutting; maybe very weak flicker |
| **Fuller cleaned** | Enemy-proximity **glow unlocked** |
| **Guard contact cleaned** | Readable hilt **vibration/audio pulse** — useful even sheathed |
| **Polished detection** | Distinguishes **threat intensity** by glow rhythm |

### Requirements

Grindstone, forge tools, fine polishing kit / oil / wire brush, and **training
with the sword** to interpret glow patterns. (Maps to forge progression — see
`../Mechanics/forge-and-upgrades.md`.)

## What the glow detects

- Active hive bodies.
- Attended enemies.
- Root nodes.
- Later (upgraded): environmental hive organs / mud / listening stones.

### What it does NOT detect

Normal humans, animals, pure traps, or **dormant** bodies — unless upgraded.

## Interaction with Arghanzza

- Glow helps detect hidden **pine-husks, hive-mud, active root nodes,** and
  environmental hive organs.
- **Silent rocks** may **absorb/dim** the glow.
- The hive may later **mimic or spoof** the glow under high pressure — especially
  in Arghanzza.

This makes detection a **gating tool** for Arghanzza: with it, crossing is
easier; without it, the player must solve environmental clues manually. (See
`../Regions/Arghanzza/traversal.md`.)
