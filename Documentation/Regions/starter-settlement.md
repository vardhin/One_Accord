# Starter Settlement (Goodsprings-scale)

> The first breathable pocket of civilization. Small, legible, tutorial-rich,
> political, systemic. Scale inspiration: Goodsprings (Fallout: New Vegas).

## Scale & tone

Heavy inspiration from **Fallout: New Vegas / Fallout 3.** The first settlement is
**Goodsprings-scale:** small, legible, tutorial-rich, political, and systemic. Not
a giant city.

A **basic safe settlement** with:

- A **three-day quarantine rule** (the tutorial — see
  `../Player/opening-and-tutorial.md`).
- Crude defenses.
- Around **5 core NPCs** (see `../Npcs/starter-npcs.md`).

## Layout

- Outer quarantine yard.
- Gatehouse.
- Well.
- Storehouse.
- Healer shed.
- Forge lean-to.
- Training yard / militia post.
- Common room / ration hall.
- Corpse pit / ash trench.

## The first conflict (Goodsprings-style)

A small local crisis that teaches the whole game. Possible crisis:

> A quarantined traveler is **accused of turning before the third night.**

Stakeholder tensions:

- **Guard** wants to burn early.
- **Healer** says it's unclear.
- **Quartermaster** worries about supplies.
- **Trainer** worries about defense.
- **Blacksmith** needs yard access / tools.
- **Sword** may **contest** the killing (Stillpoint — see
  `../Mechanics/stillpoint.md`).

This single crisis surfaces: mercy dilemmas, bounded knowledge, resource
allocation, the sword's agency, and quarantine procedure — the whole game in
miniature.

## Helping before the breach

The player can help each of the five NPCs first; those choices **change the
fight.** (Detailed in `../Npcs/starter-npcs.md`.)

## Upgrade ceiling

The first settlement should **NOT** unlock full upgrades — only **basic
maintenance**, especially the **grindstone → sharpening** chain. (Forge Level 0→1
only; see `../Mechanics/forge-and-upgrades.md`.)

## Possible Arghanzza dependency

The starter settlement may need **Arghanzza resources** to progress: charcoal for
the forge, herbs for the healer, a salvage team, a blueprint, a bell clapper, an
ash formula, or an old guide. (See `Arghanzza/region-arghanzza.md`.)
