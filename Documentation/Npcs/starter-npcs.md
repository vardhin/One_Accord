# Starter Settlement NPCs (The Core Five)

> The first settlement is Goodsprings-scale with ~5 core NPCs. Each teaches a
> slice of the whole game. See `../Regions/Magizhee/region-magizhee.md` for the place.

## The five roles

### 1. Guard Captain / Gatekeeper

Law, quarantine, access, settlement suspicion, **sword registration/confiscation
pressure.** Teaches gate rules and bell codes. Literacy domain: gate, outside,
wait, open, close, dusk, three.

### 2. Healer / Plague Watcher

Infection diagnosis, healing, ash/cold basics, **fresh-infected ethics, mercy
dilemmas.** Literacy domain: sickness, fever, blood, breath, sleep.

### 3. Blacksmith / Repair Worker

Grindstone, basic sharpening, **forge seed**, tool repair. The entry point to the
forge progression (`../Mechanics/forge-and-upgrades.md`). Blacksmith improvement
is character progression.

### 4. Trainer / Militia Veteran

Stamina, dodge/block, sword handling, **nonlethal combat**, other-weapon basics.
The combat tutor (`../Mechanics/combat-system.md`).

### 5. Quartermaster / Trader / Organizer

Resources, supplies, the **quest loop**, settlement upgrades, **allocation
choices.** The seed of the village/union system
(`../Mechanics/village-and-union-system.md`).

## Helping each NPC before the crisis

Before the first breach, the player can help each NPC — and those choices **affect
the fight:**

- Guards → defenders.
- Healer → ash/cold supplies.
- Blacksmith → sharpened sword / barricade repair.
- Trainer → militia help.
- Quartermaster → extra oil/salt/supplies.
- A quarantined helper.

## What they teach about the world

These five collectively teach: procedure, suspicion, bounded knowledge, mercy
dilemmas, the sword's social danger, the forge loop, combat, and resource
allocation — the whole game in miniature, Goodsprings-style.
