# System NPC Roles & Facilities

> Every mechanic needs a home, a person, and a reason to exist. With ~7 regions
> and ~40 NPCs, this is a hard budgeting constraint.

## Core system NPCs needed

- **Trainer** — sword/combat training.
- **Blacksmith** — forge, repair, sharpening.
- **Glyph master** — glyph research & magic weapons (`../Glyphs/glyph-system.md`).
- **Guard captain** — law, access, quarantine, defense.
- **Healer / plague watcher** — diagnosis, healing, mercy.
- **Quartermaster** — resources, supplies, allocation.
- **Rite / spell instructor** — spellcasting training.
- **Decoder / scribe / archive person** — literacy, blueprints, records.

## Core facilities

- **Forge** — sword & weapon upgrades.
- **Glyph workshop** — glyph crafting.
- **Training yard** — sword training.
- **Rite / spell practice hall** — spellcasting training.
- **Archive / decoder** — knowledge, blueprints, records.
- **Infirmary** — healing, quarantine treatment.
- **Gatehouse** — access control, quarantine procedure.
- **Storehouse** — supplies, allocation.

## Every NPC does at least one thing

A named NPC should be able to do **at least one** of:

unlock a facility · improve a facility · train a skill · decode knowledge · craft
something · change access · change settlement policy · create moral conflict · be
assignable to a task.

## Activity → place → person mapping

| Activity | Place | Person |
| --- | --- | --- |
| Sword training | Training yard | Trainer / militia veteran |
| Spellcasting training | Rite/spell practice hall | Rite/spell instructor |
| Sword upgrades | Forge | Blacksmith (+ glyph master/healer at high levels) |
| Magic weapon crafting | Glyph workshop | Glyph master |
| Literacy / decoding | Archive / decoder | Decoder / scribe |
| Healing / quarantine | Infirmary | Healer / plague watcher |
| Access / defense | Gatehouse | Guard captain |
| Supplies / allocation | Storehouse | Quartermaster |

## Companion weapons

Magic companion weapons exist but are **not as special as the sword.** Examples
mapped to NPC roles: guard salt-pikes, scout bell-knife, healer cold-needle,
corpse-burner ash-axe. (See `../Glyphs/glyph-system.md` and
`../Mechanics/forge-and-upgrades.md`.)
